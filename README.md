# trading-engine-java

内存交易撮合与成交回放（Spring Boot 3 / Java 21，纯内存、零外部依赖即可运行）。

* 限价单 / 市价单（IOC）/ 撤单 / 改单，价格优先 + 时间优先；
* 多账户并发委托与限额校验，成交序列与余额对并发调度无关；
* 拒绝原因可区分（非法量价、未知委托、自成交、资金/持仓不足、超限、无流动性、重复指令）；
* 订单簿/账户/成交/拒绝的确定性快照导出与 JSON 往返，快照恢复 + 增量回放可复现；
* 重复回放不产生重复成交、不发生状态漂移。

## 盘中扩展能力

* **委托组原子提交**：一组委托按序依次撮合，任意一条不合法则整组回滚、零残留；
  成功时逐条撮合结果可单独查询；整组被拒（BATCH_REJECTED）与组内某条自身被拒可区分。
* **不停机一致性快照**（StreamingGateway）：多账户边写边导，快照落在撮合全序的明确
  指令边界，不夹在指令中间；采集只做内存拷贝、JSON 在锁外序列化，不长时间卡写入；
  恢复到新实例继续撮合/撤改，结果与从未导出的实例在每笔委托数量拆分和账户余额上逐项一致。
* **盘后对账摘要**（Reconciler）：按账户/标的输出订单数、成交笔数、成交量、现金、持仓的
  确定性摘要；一致即状态一致，不一致可定位到具体账户/标的/维度；同状态两次摘要逐字节相同。

## 快速开始

```bash
mvn test                # 29 个撮合/并发/快照/原子组/对账单测 + Spring 冒烟
mvn compile exec:java   # 端到端演示：撮合→并发→原子组→在线快照→恢复续跑→对账
```
