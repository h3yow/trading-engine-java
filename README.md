# trading-engine-java

内存交易撮合与成交回放（Spring Boot 3 / Java 21，纯内存、零外部依赖即可运行）。

* 限价单 / 市价单（IOC）/ 撤单 / 改单，价格优先 + 时间优先；
* 多账户并发委托与限额校验，成交序列与余额对并发调度无关；
* 拒绝原因可区分（非法量价、未知委托、自成交、资金/持仓不足、超限、无流动性、重复指令）；
* 订单簿/账户/成交/拒绝的确定性快照导出与 JSON 往返，快照恢复 + 增量回放可复现；
* 重复回放不产生重复成交、不发生状态漂移。

## 快速开始

```bash
mvn test            # 17 个撮合/并发/快照回放单测 + Spring 冒烟
mvn compile exec:java   # 端到端演示：撮合→并发→快照→恢复→重复回放
```

规则、确定性原理与验证方法详见 [MATCHING_ENGINE.md](MATCHING_ENGINE.md)。
